# 如何配合使用微信开发者工具

开发者工具是 **编译器 + 模拟器 + 云控制台**，不是小程序源码。完整软件在：

`D:\0901微信小程序工作台\tools\微信web开发者工具\`

请用这一份打开项目。根目录若还留着同名文件夹，那是上次移动时被占用的残留文件，不要用来打开项目。

## 1. 打开工程（每次开发）

1. 启动 `tools\微信web开发者工具` 里的「微信开发者工具」。
2. 用微信扫码登录（必须是 AppID `wx44b8ea3d94ca4052` 的开发者）。
3. 选择 **打开项目**，目录选：

   `D:\0901微信小程序工作台\慢系统`

   不要选工作台根目录，也不要选 `miniprogram` 里层。必须选带 `project.config.json` 的 `慢系统` 这一层。

4. 确认右上角 AppID 为 `wx44b8ea3d94ca4052`，项目名「慢系统」。
5. 左侧模拟器应出现「今日 / 关注 / 我的」。若报找不到页面，检查打开的是不是错目录。

本仓库已开启 TypeScript 编译插件。保存 `.ts` 文件后会热重载。

## 2. 开通云开发（只需一次）

1. 工具栏点击 **云开发**。
2. 按提示开通（个人主体即可）。记下 **环境 ID**（形如 `cloud1-xxxxx` 或 `xxx-xxxxxx`）。
3. 打开 `慢系统/miniprogram/config.ts`，把 ID 填进 `CLOUD_ENV_ID`。若只有一个环境，可暂留空。
4. **给云函数目录绑定环境（上传前必做）**  
   若右键上传出现：`请在编辑器云函数根目录（cloudfunctionRoot）选择一个云环境`，说明还没绑定，按下面做：
   1. 在左侧文件树点选 **`cloudfunctions` 文件夹本身**（不是里面的 `api`）。
   2. 看编辑器上方或右侧是否出现 **云环境** 下拉框，选你刚开通的环境。
   3. 若没有下拉框：右键 **`cloudfunctions`** → 找 **更多设置 / 当前环境 / 选择云环境** 之类菜单，选同一环境。
   4. 也可：云开发控制台打开后，确认左上角当前环境正确，再回到文件树绑定一次。
   5. 绑定成功后再右键 `cloudfunctions/api` → **上传并部署：云端安装依赖**。
5. 云开发控制台 → 数据库 → 新建集合（名称必须完全一致）：

   - `users`
   - `plans`
   - `plan_members`
   - `checkins`
   - `nudges`

6. 每个集合的权限：选 **所有用户不可读写**（由云函数代写）。若控制台没有这项，选最严格的仅管理端/云函数可写。
7. 对 `cloudfunctions/nudgeExpire` 同样上传。它带 5 分钟定时触发器，上传时允许创建触发器。

没有这几步，模拟器能出页面，但点「制定计划」会提示云开发未开通。

### 常见报错

| 报错 | 处理 |
|---|---|
| 请在编辑器云函数根目录选择一个云环境 | 先点选 `cloudfunctions` 根目录并选择云环境，再上传 `api` |
| 集合不存在 | 按上面名单建齐 5 个集合 |
| Environment / env not | 检查 `config.ts` 的 `CLOUD_ENV_ID` 是否与控制台一致 |

## 3. 日常怎么改代码

| 你想改 | 用什么 |
|---|---|
| 页面文字、按钮、布局 | Cursor 改 `miniprogram/pages/...`，保存后看模拟器 |
| 样式颜色 | `app.wxss` 或页面 `.wxss` |
| 接口、连续天数规则 | `cloudfunctions/api/handlers/...`，改完必须 **重新上传云函数** |
| 只改前端 | 保存即可，不必上传 |
| 真机看效果 | 工具栏 **预览**，手机微信扫码（需同一 AppID 开发者） |

云函数在云端跑。本地改了 `handlers` 却不上传，模拟器仍走旧逻辑。

## 4. 和 Cursor 如何分工

- **Cursor**：改源码、改文档、Git 提交。
- **微信开发者工具**：编译 TypeScript、模拟器、上传云函数、预览、看 `console`。

两套工具对着 **同一份** `慢系统` 文件夹。不要复制出第二份工程。

## 5. 调试

- 模拟器下方 **Console**：前端 `console.log` 和报错。
- 云开发 → 云函数 → 日志：后端报错（集合不存在、缺索引等）。
- 若提示需要索引：点日志里的「去创建」，不要手写错字段。

## 6. Git 在哪一层

仓库初始化在 `慢系统`，不是工作台根目录。不要把 `tools/微信web开发者工具` 加进 Git。

本机 Git：`D:\Git\Git`  
本机 Node / npm：`D:\Node`（给编辑器类型和云函数依赖用，小程序运行不靠本地 Node）。

## 7. 第一期验收路径

1. 模拟器打开「今日」→ 制定「每天阅读」。
2. 详情页点「分享给亲友」（真机才有完整分享；模拟器可先自己打卡）。
3. 第二台手机或另一个测试号打开分享卡片 → 关注 → 督促。
4. 执行者 30 分钟内完成或选择延迟。
5. 双方看到连续天数、累计天数、累计时长、阶段名、督促状态。
