# 慢系统

可被亲友看见的计划与督促小程序。灵感来自《思考，快与慢》：用轻松的最小动作（系统 1）完成每日进度，用阶段目标（系统 2）看清方向。

当前仓库是 **第一期试验版**：自己的计划、分享关注、打卡统计、30 分钟督促闭环。

## 技术框架

- 前端：微信原生小程序 + TypeScript（WXML / WXSS / TS）
- 后端：微信云开发（云函数 + 云数据库 + 云存储）
- 版本管理：Git（本仓库这一层，不要提交 `tools` 里的开发者工具）

文档入口：**[docs/README.md](./docs/README.md)**（框架、模块对照、云能力、开发者工具用法都在这里）。

## 目录

```
miniprogram/          小程序前端
  pages/              页面（今日 / 制定 / 详情 / 督促 / 关注 / 我的）
  components/         可复用组件
  services/           只在这里调用云函数
  types/              类型
  utils/              日期与文案
cloudfunctions/       云函数
  api/                全部业务接口
  nudgeExpire/        每 5 分钟把超时督促标为过期
docs/                 产品与架构说明
```

## 你需要做的一次性配置

1. 用微信开发者工具打开 `慢系统` 这一层文件夹（AppID 已写入：`wx44b8ea3d94ca4052`）。
2. 点击「云开发」，开通云环境。把环境 ID 填进 `miniprogram/config.ts` 的 `CLOUD_ENV_ID`。若只有一个环境，可暂留空。
3. 在云开发控制台创建这些集合，权限选「仅创建者可读写」也可以，**推荐「所有用户不可读写」**（由云函数代写）：
   - `users`
   - `plans`
   - `plan_members`
   - `checkins`
   - `nudges`
4. 右键 `cloudfunctions/api` → 上传并部署：云端安装依赖。
5. 同样上传 `nudgeExpire`（带定时触发器）。
6. 编译运行。若控制台提示缺少索引，按提示创建即可。

## 第一期怎么试

1. 打开「今日」→ 制定「每天阅读」。
2. 进入计划详情，点「分享给亲友」。
3. 另一微信打开分享卡片，点「关注这份计划」。
4. 关注者点「轻轻督促一下」。
5. 执行者在「今日」顶部进入督促，选择 30 分钟内完成或延迟。
6. 双方在计划页看到连续天数、累计天数、累计时长、阶段目标和督促状态。
